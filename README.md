# Инструкция по микрофронтам

В данном репозитории расположена тестовая конфигурация связки микрофронтов. В данном случае используется два
микрофронта на стеках `React` и `Vue`. `React` выступает в роли хоста, `Vue` в роли remote-микрофронта.

## ВАЖНО!!
Для того, чтобы запустить полученную конфигурацию, требуется:
1. На хосте (`React`) запустить npm run dev
2. На ремоуте (`Vue`) сначала сделать билд через `npm run build` и затем запустить через `npm run preview`
Требуется это для того, чтобы React-хост мог подхватывать статический `remoteEntry.js`, генерируемый плагином `vite-plugin-federation`. 
Плагин генерирует этот файл на лету в рантайме и поэтому приходит ошибка `Failed to load remote: not found 404` в dev-режиме,
так как файл с входной точкой статически недоступен при запуске хоста.
